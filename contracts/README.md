# Shared contracts

- `fixtures/` — synthetic pose-frame sequences generated by
  `packages/core/src/fixtures/generate.ts`, used by `packages/core`'s replay tests.
  **Synthetic, not recorded human movement** — see the warning at the top of that
  generator file before using these for anything beyond exercising evaluator logic.
- `events/`, `entitlement/` — spec section 18 reserves these for versioned
  JSON-Schema/OpenAPI-style contract documents generated from `packages/types` and the
  entitlement claims shape (`packages/types/src/entitlement.ts`). Not generated yet —
  today those TypeScript types are the single source of truth; a codegen step to
  publish them as standalone schemas (for non-TypeScript native consumers to validate
  against) is follow-up work, tracked in the final build summary's open questions.
